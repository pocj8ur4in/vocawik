# pocj8ur4in/vocawik

vocawik is a wiki for Vocal Synthesizer related with Songs, Artists and more.

We use [Spring Boot](https://spring.io/projects/spring-boot), [Spring Data JPA](https://spring.io/projects/spring-data-jpa), [Spring Security](https://spring.io/projects/spring-security), [PostgreSQL](https://www.postgresql.org/), [Redis](https://redis.io/), and [React](https://react.dev/). Most of the server-side code is written in [Java](https://www.java.com/), and most of the client-side code is written in [TypeScript](https://www.typescriptlang.org/).
